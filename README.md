# Superfocus downloads

Installers for Superfocus, a simple project manager that shows you one task at a time.

- [Download for Mac (Apple silicon)](https://github.com/abhinavakhil/superfocus-releases/releases/latest/download/Superfocus-arm64.dmg)
- [Download for Mac (Intel)](https://github.com/abhinavakhil/superfocus-releases/releases/latest/download/Superfocus-x64.dmg)
- [Download for Windows](https://github.com/abhinavakhil/superfocus-releases/releases/latest/download/Superfocus-Setup.exe)

The apps are not code-signed yet, so your computer will warn you the first time.

- **Windows:** choose "More info", then "Run anyway".
- **Mac:** open System Settings, go to Privacy & Security and choose "Open Anyway".
